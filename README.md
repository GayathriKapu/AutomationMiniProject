# Automation Mini Project

This is a Selenium Automation Testing project developed using Java.

## Technologies Used
- Java
- Selenium WebDriver
- TestNG
- Eclipse IDE

## Project Description
This project automates web application functionalities using Selenium WebDriver and TestNG framework.

## Features
- Automated browser actions
- Dropdown handling
- Test execution using TestNG
- Selenium WebDriver integration

## Project Structure
- src/ → Java source files
- bin/ → Compiled class files
- test-output/ → TestNG reports
